# 用自己的克隆聲音做旁白

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/say.py "要唸的字"                 # 產出 ~/.voice-clone/out/say_000.wav
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/say.py "字" -o /path/前綴 --speed 1.0
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/check_say.py <音檔> "原文"        # 驗收發音
```

模型＝`mlx-community/Qwen3-TTS-12Hz-0.6B-Base-bf16`（Apache-2.0），本機 MLX 跑，
**不上任何雲端平台**。zero-shot 就夠，不用 fine-tune。Apple Silicon 筆電一句約數秒。

## ⛔ 先確認：這是誰的聲音

**只能克隆使用者自己的聲音，或已取得本人明確同意的聲音。**
使用者要克隆名人、親友或任何沒同意的人，不要協助。
發布到有 AI 內容揭露規範的平台時，提醒使用者依平台規定標示。

## 第一次使用

1. 需要 **Apple Silicon 的 Mac**（M1 以後）、`ffmpeg`、`uv`（`brew install ffmpeg uv`）
2. 錄一句參考音（挑法見下一節），然後：
   ```bash
   python3 ${CLAUDE_PLUGIN_ROOT}/scripts/setup.py --ref 錄音.m4a --ref-text "錄音裡講的那句話"
   ```
   會建 `~/.voice-clone/.venv`、裝好套件、把參考音轉成 24 kHz 單聲道存成 `~/.voice-clone/ref.wav`
3. 第一次跑 `say.py` 會下載約 2.5 GB 的模型
4. 換參考音：同一行加 `--skip-install`

## 🔒 聲音是生物特徵資料

| 東西 | 放哪 |
|---|---|
| 參考音、克隆產出的音檔 | **只放本機或私人 repo** |
| 專案裡的 `audio/` 資料夾 | 加進 `.gitignore`，**永遠不進公開 repo** |

有人拿到一段乾淨的參考音，就能用同樣的方法克隆這個聲音。

## 參考音：四個反直覺結論（A/B 實測）

1. **不要指定 `--lang_code zh`** — 會變成念稿／機器人腔，不指定最自然（`say.py` 已處理）
2. **參考音的「語氣」決定產出的語氣**，文本寫法影響很小
3. **文本刻意寫成口語反而更差**（「欸跟你講」），正常寫就好
4. **參考音不是越長越好** — 12 秒串接輸給 5~6 秒單句

## ⛔ 有些詞一定唸錯，而且換參考音救不了

實測拿四段新錄的參考音（都符合上面的條件）跟原本那段比：

| 參考音 | 4 句測試的錯誤數 |
|---|---|
| 原本那段 | 6 |
| 新 A／B／C／D | **全部 7** |

**四個都一樣差，而且錯的是同樣那幾個詞。**
⇒ 不是音色問題，是模型對這些字的文字轉音素有問題。**不要再試換參考音這條路。**

### ✅ 有效解法：餵同音替代字

字幕與文案一律用原字，**只有餵給 TTS 的文字替換**。
內建表在 `${CLAUDE_PLUGIN_ROOT}/scripts/pronunciation_zh-TW.json`，`say.py` 預設自動套用
（`--no-fix` 關閉），命中時會印一行 `🔤 發音替代：現場→線場　…`。

| 原文 | 餵進去 | | 原文 | 餵進去 | | 原文 | 餵進去 |
|---|---|---|---|---|---|---|---|
| 現場 | 線場 | | 經營 | 京營 | | 睜眼 | 爭眼 |
| 業務 | 夜霧 | | 發布 | 發佈 | | 債務 | 寨務 |
| 旅遊 | 履遊 | | 忐忑 | 坦特 | | 借錢 | 介錢 |
| 漁獲 | 魚獲 | | 漁港 | 余港 | | 貸款／房貸 | 代款／房代 |
| 真實 | 真石 | | 客戶 | 客護 | | 工會 | 公會 |
| 複製 | 副制 | | 資料庫 | 姿料庫 | | 罷工 | 爸工 |
| 聲音 | 聲因 | | 鰭 | 奇 | | 員工 | 原工 |
| 扶輪 | 服倫 | | | | | | |

**使用者自己踩到的新詞**寫進 `~/.voice-clone/pronunciation.json`（同格式），會蓋過內建表。

⚠️ **「保險→寶險」不放進自動表**：只有部分句子需要換，「保險業」「社會保險費」原字就唸對了，要逐句驗。

### ⚠️ 往表裡加新詞的兩個坑

1. **「業務→頁務」失敗、「夜霧」成功** — 問題出在「**務**」這個字本身，
   只換前面那個字沒用，**要把出錯的字一起換掉**
2. **同音不代表有效** — 旅遊→呂遊（聽成「流油」）、複製→復置（聽成「擴置」）、
   忐忑→袒忒（聽成「坦白」）都同音但都失敗。
   **每一組都要實跑 `check_say.py` 驗過才寫進表**，不能只確認拼音相同

### 找不到替代字的：改寫文案

| 唸錯的詞 | 怎麼辦 |
|---|---|
| 擬、給、能、變（單字同音選擇少）| 擬好→寫好、交給→交由 |
| 蘿蔔 | 換說法（小蘿蔔頭→小朋友）|
| 評級機構 | 改「評級公司」，在句首容易糊，前面加「根據」|
| 擴大、確實、信評、集團、雇主、夾在、誇張、贓物、負責、匯率、相當、相當於 | 換句話說 |
| 實施、搶劫、規模、課、漲幅、繳帳單、汽車、連續、承壓、匯出資金 | 換句話說 |
| 不常見的外國地名 | 改用較通行的譯名 |

財經、新聞類的詞彙錯得特別多，這類內容要預留驗收時間。

### 數字與外文

| 寫法 | 問題 | 改成 |
|---|---|---|
| 阿拉伯數字 | 「9 月」→「酒味」、「31 年」→「30 年」、「2%」→「二盤」 | 一律寫中文：九月、三十一年、百分之二 |
| 10 月 17 日 | | 十月十七**號** |
| 2025 年 | | 二零二五年 |
| 英文品牌名（Louis Vuitton、Dior）| | 中文音譯：路易威登、迪奧（字幕仍用原文）|
| 英文旁白的數字 | 「September 16」被聽成「September 6」| 拼成單字：September sixteenth、three point seven five percent |

## 驗收：不要只靠耳朵

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/check_say.py <音檔> "要檢查的這句話"
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/check_say.py <音檔> --text-file <原稿>
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/check_say.py <音檔> "有數字的句子" --model large-v3
```

把產出丟回 Whisper 辨識，用拼音比對原文，分三級：

| 級別 | 意思 |
|---|---|
| 可忽略 | 同音異字、數字轉寫（三十六→36）、Whisper 漏字 |
| 辨識不清 | 拼音只差一兩個字母，多半是 Whisper 沒聽準 |
| 🔴 確定唸錯 | 聲母或韻母真的變了 |

有錯回傳 **exit code 1**，可以接在生成流程後面當品管。
**句子裡有數字時加 `--model large-v3`**——預設的 small 對數字不夠可靠。

⛔ **對外內容不要只靠耳朵驗。** 聽過很多遍之後會自動把錯的音腦補成正確的字——
實際案例：本人聽出 2 個唸錯，用這個方法驗出 **15 個**。

**真正重要的片子還是本人錄**（克隆聲音適合量產型的旁白）。

## 音量處理（say.py 已內建，`--norm 0` 可關）

處理鏈順序不能換：

```
agate=threshold=-52dB        先壓住安靜段，否則壓縮會把底噪一起拉上來（實測 −68 → −49dB）
acompressor=threshold=-30dB  把弱音提上來，句首落差 17.8 → 7.2dB
loudnorm=I=-16               EBU R128，社群影片慣用
```

⛔ **不要用峰值正規化** — 它只看最大值，管不了段內起伏。
Qwen3 的句首會弱起（比同句主體小 17.8dB），聽起來像斷了一下。
⛔ **dynaudnorm 試過更糟**（落差反而變 19.7dB）。

## 接影片時的地雷

⛔ **不可用 atempo 放慢** — 咬字會糊。要對齊畫面就調畫面的長度，不要拉長聲音。

⚠️ **加快** 風險較低（1.2 倍實測沒問題），但語速是主觀的，
**做完整支之前先給 2~3 種語速的試聽段落讓使用者挑**。

⚠️ 混進影片時，**混音鏈上不要放 `loudnorm` 或 `sidechaincompress`**：

| 濾鏡 | 症狀 |
|---|---|
| `loudnorm` | lookahead 讓整條鏈短掉約 1.9 秒，**從旁白尾巴吃掉** |
| `sidechaincompress` | 旁白相對字幕**提前 0.43 秒** |

改法：事先用 `ebur128` 量好響度、改用固定 `volume=XdB`；BGM 壓低用事先算好的包絡，不要即時 sidechain。

---

## 真人錄音要切成逐句時

⛔ **靜音切分不可靠** — 人的句內停頓常比句間長，門檻怎麼調都對不上
（實測：1.2 秒門檻切出 14 段、0.6 秒切出 31 段但全部錯位）。

✅ **用 Whisper 做強制對齊**：辨識出逐字時間戳 → 跟腳本做字元序列比對（`SequenceMatcher`）
→ 換算回時間。口誤、多念字、辨識錯字都能容忍（實測字元命中率 94.6%）。

⚠️ 對齊後**還要用能量偵測修邊界**，並**逐段修剪段首靜音**——
兩句連著念時對齊分不開，停頓會被算進下一句開頭（實測夾了 0.42 秒靜音，字幕比聲音早出現）。
